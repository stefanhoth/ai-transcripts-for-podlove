## [1.0.10] - 2025-01-01
### Added
- Initial public release
- One-click transcription for Podlove Publisher episodes via AssemblyAI
- Speaker diarization support
- Transcripts imported directly into the Podlove Transcripts module
- Settings page for AssemblyAI API key configuration
- Admin meta box for per-episode transcription actions
- REST API endpoint for triggering and polling transcription jobs
- Dependency check with admin notice when Podlove modules are missing
